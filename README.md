# GitHub Pages Site
This is the main landing page youll see when going to [https://chugglebug.github.io/](https://chugglebug.github.io/), It points to other sub projects under this account.

# Website Structure

- `/ (root)`: This is essentially just a landing page. It acts as a homepage with some basic information
- `/blog`: This is just a blog site, where I write about anything I feel like
- `/app`: This is where most of the work goes. This holds any single page web apps I want to make. These are independent from this repo and can theoretically be deployed on their own. I like to call them "toys." 
  - There is an exception to this where `/stars` is considered a "toy", but is managed by root
